# 🎂 Happy Birthday Maitriii — Photo Guide

## 📸 Where to add photos

Drop your photos into the **`images/`** folder using these exact names:

| Slot | File name | Where it shows |
|------|-----------|----------------|
| 1 | `hero-photo.jpg` | Big round photo on the homepage (top) |
| 2 | `photo-1.jpg` | Gallery card 1 |
| 3 | `photo-2.jpg` | Gallery card 2 |
| 4 | `photo-3.jpg` | Gallery card 3 |
| 5 | `photo-4.jpg` | Gallery card 4 |
| 6 | `photo-5.jpg` | Gallery card 5 |
| 7 | `photo-6.jpg` | Gallery card 6 |
| 8 | `photo-7.jpg` | Gallery card 7 |
| 9 | `photo-8.jpg` | Gallery card 8 |
| 10 | `photo-9.jpg` | Gallery card 9 |
| 11 | `photo-10.jpg` | Gallery card 10 |
| 12 | `photo-11.jpg` | Gallery card 11 |
| 13 | `photo-12.jpg` | Gallery card 12 |

### Steps
1. Open the `images` folder.
2. Copy your photos there.
3. **Rename** them to match the table above (e.g. `photo-1.jpg`).
4. Refresh the website — photos appear automatically. No code changes needed!

### Tips
- Use **.jpg** or **.png** format.
- Keep names in **lowercase** exactly as shown.
- Gallery photos look best in portrait/vertical size.
- `hero-photo.jpg` should be a clear close-up of Maitriii.

## ✏️ Other customizations
- **Birthday date:** open `js/script.js` → find `const BIRTHDAY = ...` and change the month/day.
- **Wishes text:** open `index.html` → edit the paragraph in the *A Little Note For You* section.
- **Name:** search for `Maitriii` in `index.html` if you want to change the spelling.

## ▶️ How to view
Just open `index.html` in any browser (double-click it).
